# Fuentes y verificación — Claude vs ChatGPT para programar: ¿vale la pena pagar?

## Afirmaciones verificadas

- Claude Free incluye Sonnet y Haiku con uso limitado y no incluye Claude Code.
  - [Claude — Plans & pricing](https://claude.com/pricing) (consultado 2026-11-15)
- ChatGPT Free incluye GPT-6 y acceso limitado a Codex.
  - [ChatGPT — Planes y precios](https://chatgpt.com/es-419/pricing/) (consultado 2026-11-15)
- Claude Code lee la base de código, edita archivos y ejecuta comandos.
  - [Claude Code — Overview](https://code.claude.com/docs/en/overview) (consultado 2026-11-15)
- Claude Pro cuesta 20 USD/mes e incluye Claude Code.
  - [Claude — Plans & pricing](https://claude.com/pricing) (consultado 2026-11-15)
  - [Claude Help Center — Use Claude Code with your Pro, Max, or Ultra plan](https://support.claude.com/en/articles/11145838-use-claude-code-with-your-pro-or-max-plan) (consultado 2026-11-15)
- ChatGPT Plus cuesta 20 USD/mes en EE. UU. e incluye uso ampliado de Codex. NOTA: el importe en USD se confirmó en el índice de búsqueda de la página oficial; la página en vivo muestra la moneda local.
  - [OpenAI — ChatGPT Pricing (USD, vía índice de búsqueda)](https://openai.com/chatgpt/pricing/) (consultado 2026-11-15)
  - [ChatGPT — Planes y precios](https://chatgpt.com/es-419/pricing/) (consultado 2026-11-15)
- En los planes de pago de Claude, el chat y Claude Code comparten el mismo límite de uso.
  - [Claude Help Center — Use Claude Code with your Pro, Max, or Ultra plan](https://support.claude.com/en/articles/11145838-use-claude-code-with-your-pro-or-max-plan) (consultado 2026-11-15)
- Claude Max cuesta 100 USD/mes con 5 veces el uso de Pro; Claude Ultra cuesta 200 USD/mes con 10 veces el uso semanal de Pro.
  - [Claude — Plans & pricing](https://claude.com/pricing) (consultado 2026-11-15)
- ChatGPT Pro empieza en 100 USD/mes con varios niveles de uso.
  - [ChatGPT — Planes y precios](https://chatgpt.com/es-419/pricing/) (consultado 2026-11-15)
  - [Codex — Pricing](https://chatgpt.com/codex/pricing/) (consultado 2026-11-15)
