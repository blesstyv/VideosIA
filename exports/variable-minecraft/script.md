## Narración

**1. gancho** (intro)

Cuando juntas diamantes en Minecraft, el juego tiene que recordar cuántos llevas. Para eso, los programas usan variables.

**2. concepto** (desarrollo)

Imagina un cofre con una etiqueta que dice diamantes. Adentro guardas un valor: cinco. Eso es una variable: un nombre que guarda un dato para usarlo después.

**3. asignacion** (desarrollo)

En Python se escribe así: diamantes igual cinco. Ojo: el signo igual no compara, asigna. Guarda el valor en ese nombre.

**4. actualizar** (ejemplo)

Si minas tres más, escribes: diamantes igual diamantes más tres. Python calcula primero la derecha y guarda el resultado: ocho.

**5. programa** (ejemplo)

Con print muestras el valor. Al ejecutarlo, la consola imprime ocho.

**6. reglas** (desarrollo)

Tres reglas: usa nombres que describan el dato, no empieces con un número, y ojo con las mayúsculas: Diamantes y diamantes son variables distintas.

**7. cierre** (cierre)

Dato técnico: en Python, la variable es una etiqueta que apunta al valor, no la caja. Pero el cofre te sirve para empezar. ¿Qué guardarías tú en una variable?
