# Fuentes y verificación — ¿Qué es una variable en programación? Explicado con Minecraft

## Afirmaciones verificadas

- En Python, una asignación enlaza (o re-enlaza) un nombre con un valor; la variable es un nombre que hace referencia a ese valor.
  - [The Python Language Reference — Assignment statements](https://docs.python.org/3/reference/simple_stmts.html#assignment-statements) (consultado 2026-11-14)
- El signo = se usa para asignar un valor a una variable; la comparación de igualdad usa ==.
  - [The Python Tutorial — An Informal Introduction to Python (Numbers)](https://docs.python.org/3/tutorial/introduction.html#numbers) (consultado 2026-11-14)
  - [The Python Tutorial — First Steps Towards Programming](https://docs.python.org/3/tutorial/introduction.html#first-steps-towards-programming) (consultado 2026-11-14)
- En una asignación, la expresión de la derecha se evalúa antes de enlazar el resultado al nombre (diamantes = diamantes + 3 calcula 5 + 3 y guarda 8).
  - [The Python Language Reference — Assignment statements](https://docs.python.org/3/reference/simple_stmts.html#assignment-statements) (consultado 2026-11-14)
  - [The Python Tutorial — First Steps Towards Programming](https://docs.python.org/3/tutorial/introduction.html#first-steps-towards-programming) (consultado 2026-11-14)
- El programa mostrado imprime 8 (verificado ejecutándolo con Python 3.13 en el pipeline).
  - [The Python Tutorial — An Informal Introduction to Python (Numbers)](https://docs.python.org/3/tutorial/introduction.html#numbers) (consultado 2026-11-14)
- Un identificador no puede empezar con un dígito.
  - [The Python Language Reference — Names (identifiers and keywords)](https://docs.python.org/3/reference/lexical_analysis.html#names-identifiers-and-keywords) (consultado 2026-11-14)
- Los identificadores distinguen mayúsculas de minúsculas (Diamantes y diamantes son nombres distintos).
  - [The Python Language Reference — Names (identifiers and keywords)](https://docs.python.org/3/reference/lexical_analysis.html#names-identifiers-and-keywords) (consultado 2026-11-14)

## Contenido ilustrativo (analogías / ejemplos didácticos, no datos)

- Usar nombres descriptivos es una recomendación de estilo, no una regla del lenguaje.
- El cofre con etiqueta es una analogía didáctica; en Python la variable es una etiqueta que apunta al valor, como se aclara en el cierre.
- Que el juego 'recuerde' tus diamantes es un ejemplo general de estado de un programa; no describe el código interno de Minecraft.
